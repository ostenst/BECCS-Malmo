You can try running the model for 1 default scenario using model.py in your terminal.  
You can also explore all 1.000.000 scenarios by running controller.py.  
You can run scenario discovery algorithms using the cart.py script.  
You can run a Sobol sensitivity analysis using the controller_sobol.py script.  
You can use the various plot.py scripts to plot the figures of the main article.
